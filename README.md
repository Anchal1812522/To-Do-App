# 📝 To-Do List App

A simple **To-Do List Web Application** built using **HTML, CSS, and JavaScript**. This app allows users to manage their daily tasks easily.

---

## 🚀 Features

* Add new tasks
* Display tasks in a list
* Mark tasks as completed
* Remove tasks (if implemented)
* Simple and user-friendly interface

---

## 🛠️ Technologies Used

* **HTML** – for structure
* **CSS** – for styling
* **JavaScript** – for functionality

---

## 📂 Project Structure

```
To-Do-App/
│── index.html
│── style.css
│── script.js
│── README.md
```

---

## ⚙️ How to Use

1. Open the app in your browser.
2. Enter a task in the input field.
3. Click the **Add** button.
4. Your task will appear in the list.
5. Click on a task to mark it as completed.
